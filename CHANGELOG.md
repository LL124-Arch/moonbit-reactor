# Changelog

## 0.2.0

- Added engineering metrics for residence time, space time, conversion, yield, and selectivity.
- Added reversible, series, and parallel first-order kinetic helpers.
- Added explicit solver status reports and guarded trapezoid integration reports.
- Added seven source-traceable offline benchmark cases and a `cmd/benchmarks` executable.
- Expanded boundary tests for empty sweeps, invalid brackets, iteration limits, and physical conversion ranges.
- Updated README, design notes, and CI commands for strict MoonBit 0.10.x validation.

## 0.1.0

- Added CSTR, PFR, and batch design calculations.
- Added isothermal, adiabatic, and cooled non-isothermal modes.
- Added bisection, trapezoid integration, Euler integration, and sweep utilities.
- Added example cases and runnable CLI demo.
- Added tests, documentation, Apache-2.0 license, and GitHub Actions CI.
